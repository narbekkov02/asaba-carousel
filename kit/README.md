# Асабалық өнер — Instagram күнделікті контент жинағы (kit)

Тапсырыс беруші: Нұрбек Бүркітбайдың продюсері. Аккаунт: @nurbek_burkitbay (Instagram, Windsor арқылы қосылған, account id 17841456202473153).
Тіл: қазақша (қарапайым, жалпақ тілмен, жүрекке тиетін).

## Күнделікті тәртіп
- Күн сайын 1 пост. Формат: **дауыссыз видео (Reels)**, 1080×1920, 45–60 сек.
- Жоспар бойынша келесі күннің видеосын дайында → обложка → қысқа сипаттама → бәрін продюсерге **бекітуге** жібер.
- Продюсер «ОК» дегенде ғана жариялау. Жариялау уақыты: **17:00 (Asia/Almaty)**. «ОК» болмаса — жарияламау.
- **Сторис салма** (продюсер өзі салады). **Комментарийлерге жауап берме** (оларды чат-бот жауап береді).
- Озвучка жоқ. Дауыс тек продюсер аудио жіберсе ғана.

## TikTok
- TikTok нұсқасы = Instagram видеосы + соңына «Күн сайын 23:00 тікелей эфир» картасы (`cta/stream.html`, 6 сек):
  `python3 kit/tools/add_stream.py posts/<күн>/video.mp4 posts/<күн>/video_tiktok.mp4`. Instagram-ға бұл карта керек емес.
- TikTok-қа ТЕК продюсер нақты команда бергенде саласың (Metricool арқылы). Бекітуге екі нұсқаны да жібер.

## Бренд пен дизайн
- Түстер: қызыл #9B0E12 / ашық қызыл #E0262D, қара #0F0F0F, ақ. Шрифт: **Montserrat** (бір ғана отбасы; тақырып 900 uppercase, мәтін 600–800, акцент italic). Басқа шрифт араластырма.
- Динамика: әр жаңа жолда «камера серпіліп» жақындайды, тақырыптар үлкейіп орнына түседі, көрініс ауысқанда ақ жарқыл, карточкалар, иконкалар (inline SVG), бөлшектер, прожектор сәулесі. Үлгі: `templates/day_video_example.html`.
- Барлық мәтін қауіпсіз аймақта: жоғарғы 250px пен төменгі 300px және оң жақтағы 120px бос.
- Соңы әрқашан **3D кітап CTA** (`cta/cta.html`, 14,5 сек): кітап ұшып келеді, айналады, ашылады, парақтар ауысады, мазмұны шығады, соңында «Комментке «+» қалдыр».
- Фон дыбысы: өзіміз синтездеген эмбиент + әр анимацияға SFX (make_video.py өзі жасайды). Музыка/авторлық трек қолданба.
- Обложка: 1080×1920, бар мәтін ортаңғы 4:5 аймақта (y 285–1635), адамды бірден ұстайтын хук (үлгі: 2026-11-13 cover).

## Мазмұн ережесі
- Тегін контентте кітаптың мәтінін толық берме — кітап стилінде өзің жаңадан жаз.
- Жалған цифр, ойдан шығарылған табыс уәдесі болмасын.
- CTA (барлық жерде): тек **«Комментке «+» қалдыр»**. Эфир уақытын жазба.

## Техника
1. `mkdir -p ~/.fonts && cp kit/fonts/*.ttf ~/.fonts/ && fc-cache -f`
2. Күннің бөлігін `posts/YYYY-MM-DD/part.html` етіп жаз (үлгі бойынша; `window.render(t)`, `window.T_END`, `window.SFX` міндетті; emoji қолданба — шрифтте жоқ).
3. `python3 kit/tools/make_video.py posts/YYYY-MM-DD/part.html posts/YYYY-MM-DD/video.mp4`
4. Обложка: part.html-ден кадр + хук мәтіні → `posts/YYYY-MM-DD/cover.jpg`.
5. Кадрларды тексер (бірнеше кадрды кішірейтіп қара), сосын продюсерге видео + обложка + сипаттама жібер.
6. Бекітілгеннен кейін: `posts/YYYY-MM-DD/` git push (main) → Windsor `instagram` / `create_video_post`:
   video_url = https://raw.githubusercontent.com/narbekkov02/asaba-carousel/main/posts/YYYY-MM-DD/video.mp4,
   cover_url = …/cover.jpg, share_to_feed = true, caption = сипаттама.
